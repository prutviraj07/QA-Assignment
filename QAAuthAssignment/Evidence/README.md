# Evidence

This folder is where automation run artifacts should be placed after executing
the Playwright suite against the live application:

- `playwright-report/` — HTML report (auto-generated by `npm run report`)
- Screenshots and videos for any failed test (auto-captured per `playwright.config.js`)
- Manual test execution screenshots (e.g. registration success screen, 401 error on
  invalid login, dashboard redirect) can also be added here, named per Test Case ID,
  e.g. `TC_LOGIN_002_401_unauthorized.png`.

No live application was available in this environment to execute the automation
against, so this folder currently contains no run artifacts. Once pointed at a
real environment (`BASE_URL`), running `npm test` from the `Automation/` folder
will populate this directory automatically.
